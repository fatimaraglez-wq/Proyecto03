# Proyecto 003 (Vite + Preact + React Router)

    npm install
    npm run dev

## Rutas
| Ruta | Vista |
|------|-------|
| `/` | Inicio |
| `/login` | Iniciar sesión (redirige a `/usuario/:nombre`) |
| `/registro` | Registro (redirige a `/login`) |
| `/usuario/:nombre` | Perfil del usuario |
| `/personajes` | Listado Rick and Morty con buscador |
| `/personaje/:id` | Información de un personaje por ID |
| `*` | Error 404 con botón al inicio |
